# Business Entity Resolution

Initial utility for Unicode-safe text normalization and name/address similarity.

## Setup

From the repository root, create a virtual environment and install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\code\business_entity_resolution\requirements.txt

.\.venv\Scripts\python.exe .\code\business_entity_resolution\src\normalize.@'
